# 悬停聚焦（HoverFocus）

一个原生 macOS 菜单栏工具。鼠标在另一个可见窗口内连续停留一段时间后，它会激活并置前该窗口，但不会生成鼠标点击。

## 第一版行为

- 默认停留时间为 800 毫秒，菜单可选 100、200、300、500、800、1200 或 1500 毫秒；设置页可从 100 至 2000 毫秒连续调节。
- 鼠标可在同一窗口内部移动；只有离开该窗口或进入另一窗口才会重新计时。
- 拖拽、鼠标按键、滚动、键盘输入和窗口刚切换后的保护期内不会激活窗口。
- 支持同一应用内的多个窗口。
- 本软件的完整设置窗口也支持悬停聚焦；菜单栏弹出面板仍保持排除。
- 使用 AppKit 原生窗口命中测试区分实际鼠标目标与透明系统层，再以窗口编号匹配辅助功能窗口。
- 对微信等自绘内容界面提供保守的窗口边界备用识别，不读取窗口像素或聊天内容。
- 菜单栏可暂停或恢复，全局快捷键为 `⌃⌥⌘H`。
- 状态栏采用紧凑控制面板，提供运行开关、停留时间、权限状态和设置入口。
- 完整设置窗口包含通用、行为和外观三个页面。
- 停留时间和切换冷却可连续调节，并可分别控制滚动与键盘输入保护。
- 菜单栏图标提供光标、焦点、注视和窗口四种样式。
- 应用图标以重叠窗口、悬停光标和青色焦点光环表现核心功能，并提供 16 至 1024 像素的 macOS 图标资源。
- 登录启动由用户主动开启，默认关闭。
- 不显示 Dock 图标、悬浮倒计时或窗口闪框。

## 隐私

应用只使用辅助功能权限识别并置前窗口。它不会：

- 模拟鼠标点击；
- 读取网页或文档内容；
- 截取屏幕；
- 连接网络或上传数据。

## 下载与安装

普通用户应从 GitHub 的 **Releases** 页面下载 `HoverFocus-版本号-arm64.dmg`，而不是下载 GitHub 自动生成的 Source code 压缩包。

1. 打开 DMG，将 HoverFocus 拖入“应用程序”。
2. 首次打开应用，并按照提示授予辅助功能权限。
3. 当前 GitHub 测试版采用本地临时签名，尚未经过 Apple 公证。如果 macOS 阻止启动，请在“系统设置 → 隐私与安全性”中确认来源后选择“仍要打开”。

当前构建仅适用于 Apple 芯片 Mac，最低支持 macOS 13。每个版本的 DMG 都附带 SHA-256 校验值。

## 构建与运行

1. 保持当前 macOS 15，无需升级 macOS 26。
2. 从 Apple 安装与当前系统兼容的 Xcode 16.4。
3. 用 Xcode 打开 `HoverFocus.xcodeproj`。
4. 选择 `HoverFocus` scheme 和 “My Mac”，然后构建。
5. 为了让辅助功能授权保持稳定，将构建得到的 `HoverFocus.app` 固定放在 `/Applications` 后再启动并授权。

首次启动会解释辅助功能权限的用途。使用本地临时签名的版本升级后，如果系统不再认可新版身份，应用会在该版本中重新提醒一次。若系统没有自动打开正确页面，可从菜单栏选择“授权辅助功能…”或“重新检查权限”。

仅安装 Command Line Tools 时，可运行 `zsh Tools/build-local.sh`，使用本机 macOS 15.5 SDK 构建和本地签名。安装到固定目录有助于避免选错副本，但临时签名的代码身份会随构建变化，不能保证保留辅助功能授权。如果更新后开关开启却仍提示未授权，需要从辅助功能列表移除旧条目，再添加 `/Applications/HoverFocus.app`。

## 测试

在 Xcode 中选择 **Product → Test**，运行 `HoverFocusTests`。状态机测试覆盖停留触发、跨窗口重置、输入保护、冷却时间、提前触发纠正和停留时间变更。

仍需在真实桌面环境手动验证 Safari、预览、文本编辑器、多显示器、全屏、不同空间、台前调度和 Mission Control；这些行为涉及系统窗口服务器，不能由单元测试可靠模拟。

本地构建还会生成三项开发检查：`Build/Checks/WindowDiagnostics` 只读取窗口编号、边界和 AX 返回码，默认检查微信；`Build/Checks/WindowRegressionChecks` 用临时测试窗口验证自家设置窗口聚焦、菜单面板排除与失效窗口保护；`Build/Checks/WindowActivationCheck com.tencent.xinWeChat` 会实际置前一次露出的微信窗口，并检查最终焦点。所有检查均不读取用户窗口标题或内容，也不合成鼠标点击。

## 工程结构

- `HoverFocusApp`：菜单栏界面、权限、输入监听、窗口识别和激活。
- `HoverFocusCore`：不依赖界面的悬停决策状态机。
- `HoverFocusTests`：状态机 XCTest 测试。

最低部署版本为 macOS 13，使用 Swift 6，不包含第三方依赖，App Sandbox 关闭。
