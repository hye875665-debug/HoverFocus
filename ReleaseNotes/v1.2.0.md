# HoverFocus 1.2.0

首个 GitHub 测试版本，适用于 Apple 芯片 Mac，最低支持 macOS 13。

## 主要功能

- 鼠标在目标窗口停留后自动将该窗口置前，不模拟点击。
- 支持跨应用窗口、同一应用的多个窗口、微信窗口和 HoverFocus 设置窗口。
- 在拖拽、滚动和键盘输入时提供防误触保护。
- 菜单栏快速开关、停留时间选择和 `⌃⌥⌘H` 全局快捷键。
- 提供完整设置窗口及多种菜单栏图标样式。
- 不读取网页、文档或聊天内容，不截屏，不连接网络。

## 安装

1. 下载 `HoverFocus-1.2.0-arm64.dmg`。
2. 打开 DMG，将 HoverFocus 拖入“应用程序”。
3. 首次打开后，按照提示授予辅助功能权限。

## 重要说明

这个测试版本采用本地临时签名，尚未经过 Apple 公证。macOS 可能阻止首次启动；确认文件来自本仓库后，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。

应用更新后，本地临时签名会发生变化，macOS 可能要求重新授予辅助功能权限。
